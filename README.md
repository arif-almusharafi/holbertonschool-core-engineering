# Holberton School - Core Engineering

Python exercises from the Core Engineering track at Holberton School.
Each folder is one project, and each exercise is a small Python file.

## Projects

| Folder | What is inside |
| --- | --- |
| [python_fundamentals](python_fundamentals/) | `hello_world`, `control_flow`, `core_data_structures`, `functions_modules`, `exception_handling` |
| [python_oop](python_oop/) | `classes_and_object_model`, `inheritance`, `abc` (abstract base classes) |
| [python_advanced](python_advanced/) | `file_handling` |

## Topics

- Python basics: variables, conditions and loops
- Core data structures
- Functions and modules
- Error handling with `try` / `except`
- Object-oriented programming: classes, objects and inheritance
- Abstract base classes
- Working with files

## Repository structure

```text
holbertonschool-core-engineering/
├── python_fundamentals/
├── python_oop/
├── python_advanced/
└── README.md
```

## How to run

You need Python 3. Go to a project folder and run a file:

```bash
python3 file_name.py
```
